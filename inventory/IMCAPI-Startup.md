## How to use this file

1. **Look before you write.** Search this file for the symbol name/route you need. If it exists, extend or call it — do not re-implement it in another file.
2. **Fetch code by range, not by repo.** Every entry carries `path:line`; open only that file (or that range plus ~10 lines) and only the files listed under *Impact* for the symbol you touch.
3. **Before changing a signature, read its Impact line** — every listed caller must be updated in the same change. Transitive impact = walk *Impact* up one level at a time.
4. **Notation:** `→` calls, `←` called by, `(Lnn)` source line, `kind` is one of `method|constructor|property|type|interface|object|component|function`. A listed call without a target (`?`) is framework/dynamic and cannot be traced statically.
5. **Absence is not proof.** Dynamic dispatch, reflection, templates, generated code and unsupported languages are not indexed (see *Coverage*). Grep before concluding a symbol is unused.
6. **Never paste this document or a whole source file into the conversation as "context".** Cite `path:line` and read only what the change needs: anything quoted into the prompt is re-sent on every later turn.
